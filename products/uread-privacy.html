隐私政策

生效日期: 2026-08-09 · URead

URead 不联网、不需要账号、不收集任何个人数据。所有内容随 App 一起打包，拆解与朗读全部在你的设备上完成。选取的图片仅在本机识别文字，不会上传也不会保存。已拆解的句子只保存在你设备本地，未开启云端同步。购买由 Apple 处理，我们不会接触你的支付信息。

以下每一条都可以在源码中直接验证，不是宣传话术。

不联网

代码库里不存在任何网络 API 调用——没有 URLSession，没有 URLRequest，没有任何 HTTP 客户端。整个 App 可以在断网状态下使用。我们没有服务器，也没有任何后端可以接收你的数据。

没有任何第三方依赖

无 SPM 包，无统计 SDK，无崩溃上报，无广告框架。全部代码只 import Apple 系统框架。

不收集任何数据

没有账号系统，没有 API Key，不做用户追踪，也不会请求 IDFA / ATT 授权。我们不收集、不接收、不传输、不存储你的句子、图片或任何使用数据。

具体到每项功能

功能数据如何处理
粘贴的句子只在本机内存与本地数据库中，不外发
图片取句使用系统选图器（进程外选图，不申请相册权限，Info.plist 中无任何 UsageDescription）；OCR 由 Vision 框架在本机完成，图片不上传、不留存
分享扩展文字经 App Group 传给主 App，不出设备
已拆解的句子存在本地数据库（App 沙盒容器内），未开启 iCloud 同步，卸载即删除
拆解任意句子使用 Apple 端上智能，推理在设备上完成，不联网
内购由 Apple StoreKit 处理，开发者不接触也不接收任何个人信息或支付信息
朗读系统语音合成，本机完成

App Store 隐私标签

全部选项均为「未收集数据」（Data Not Collected）。

儿童

URead 不收集任何人的信息，包括儿童。

本政策的变更

若未来版本引入任何与数据相关的功能，我们会更新本政策，并在此以新的生效日期注明变更。
